# KIT framework deployment

Information and user manual: https://rox-architecture.github.io/kit-user-manual/

## Run with GUI

```bash
docker compose --profile gui pull
docker compose --profile gui up -d
```

## Run without GUI (headless)

```bash
docker compose pull
docker compose up -d
```
